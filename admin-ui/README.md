# Админ-панель для дневника тренировок

Веб-интерфейс для просмотра статистики и данных по тренировкам.

## Технологии

- **React 18** — UI библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **TailwindCSS** — стилизация
- **React Router** — маршрутизация
- **Recharts** — графики и диаграммы
- **Lucide React** — иконки
- **date-fns** — работа с датами

## Установка

```bash
yarn install
```

## Запуск

### Режим разработки
```bash
yarn dev
```

Приложение будет доступно на `http://localhost:5173`

### Сборка для продакшн
```bash
yarn build
```

Собранные файлы будут в папке `dist/`

## Структура

```
src/
├── pages/              # Страницы приложения
│   ├── Dashboard.tsx   # Главная панель со статистикой
│   ├── UsersPage.tsx   # Список пользователей
│   ├── UserDetail.tsx  # Детальная информация о пользователе
│   ├── ExercisesPage.tsx # Список упражнений
│   └── ExerciseDetail.tsx # Детальная информация об упражнении
├── App.tsx             # Главный компонент с роутингом
├── main.tsx            # Точка входа
└── index.css           # Глобальные стили
```

## Страницы

### Главная панель (/)
Отображает общую статистику:
- Всего пользователей
- Активных пользователей за неделю
- Тренировок сегодня
- Всего подходов
- Количество упражнений

### Пользователи (/users)
Список всех пользователей с информацией:
- Имя/username
- Количество дней тренировок
- Всего подходов
- Дата последней тренировки

### Детали пользователя (/users/:id)
Подробная информация о пользователе:
- Статистика (дни, подходы, упражнения)
- График прогресса за 30 дней
- Таблица статистики по упражнениям
- История всех тренировок
- Информация об оплате

### Упражнения (/exercises)
Список всех упражнений, сгруппированных по категориям

### Детали упражнения (/exercises/:id)
Статистика по упражнению:
- Общее количество подходов
- Количество пользователей
- Максимальный вес
- График прогресса весов за 90 дней
- Статистика по пользователям
