# Telegram-бот дневника тренировок

Telegram-бот для ведения дневника тренировок с использованием grammY (TypeScript) и SQLite.

## Функции

- 📝 Запись выполненных упражнений с весом и количеством повторений
- 📊 Просмотр истории тренировок по дате или периоду
- 🎯 Удобный выбор упражнений через inline-кнопки
- 💾 Локальное хранение данных в SQLite
- 🖥️ Веб-админка для просмотра статистики и данных по тренировкам

## Установка

1. Клонируйте репозиторий
2. Установите зависимости для бота:
```bash
yarn install
```

3. Установите зависимости для админки:
```bash
cd admin-ui && yarn install && cd ..
```

4. Создайте файл `.env` на основе `.env.example`:
```bash
cp .env.example .env
```

5. Добавьте токен вашего Telegram-бота в файл `.env`:
```
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_PORT=3000
```

## Запуск

### 🚀 Быстрый старт (всё вместе)

#### Продакшн (рекомендуется)
```bash
# Сборка всего проекта (бот + админка)
yarn build

# Запуск бота и админки одновременно
yarn start
```

После запуска:
- Telegram-бот будет работать
- Админка будет доступна на `http://localhost:3000`

### 📦 Раздельный запуск

#### Telegram-бот

**Режим разработки:**
```bash
yarn dev
```

**Продакшн:**
```bash
yarn build
yarn bot
```

#### Веб-админка

**Режим разработки (frontend):**
```bash
yarn admin:dev
```

**Запуск сервера админки:**
```bash
yarn admin
```

**Сборка frontend для продакшн:**
```bash
yarn admin:build
```

## Команды бота

- `/start` — начало работы с ботом
- `/help` — краткая справка по командам
- `/add` — добавить новое упражнение и первый подход за сегодня
- `/addset` — добавить дополнительный подход к уже выполненным сегодня упражнениям
- `/history` — посмотреть историю тренировок (за дату или период)
- `/pay` — записать оплату (дата начала и количество оплаченных тренировок)
- `/remaining` — показать, сколько оплаченных тренировок осталось

## База данных

Бот использует SQLite с четырьмя таблицами:
- `users` — информация о пользователях (id, telegram_id, created_at)
- `exercises` — список доступных упражнений (id, name)
- `workouts` — записи тренировок (id, user_id, exercise_id, weight, reps, set_number, created_at)
- `payments` — данные об оплате (user_id, start_date, paid_sessions, last_notified_at)

## Веб-админка

Админ-панель предоставляет удобный интерфейс для просмотра данных:

### Возможности
- **Главная панель** — общая статистика (пользователи, тренировки, активность)
- **Пользователи** — список всех пользователей с их статистикой
- **Детали пользователя** — подробная информация о тренировках конкретного пользователя:
  - График прогресса за последние 30 дней
  - Статистика по упражнениям (средний/максимальный вес)
  - История всех тренировок
  - Информация об оплате
- **Упражнения** — список всех упражнений по категориям
- **Детали упражнения** — статистика по конкретному упражнению:
  - График прогресса весов за 90 дней
  - Статистика по пользователям

### API Endpoints
- `GET /api/stats` — общая статистика
- `GET /api/users` — список пользователей
- `GET /api/users/:userId/workouts` — тренировки пользователя
- `GET /api/users/:userId/stats` — статистика пользователя
- `GET /api/exercises` — список упражнений
- `POST /api/exercises` — создание нового упражнения
- `GET /api/exercises/:exerciseId/stats` — статистика упражнения
- `PUT /api/exercises/:exerciseId` — обновление упражнения (название и категория)

## Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен в файл `.env`
