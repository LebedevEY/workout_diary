# Руководство по использованию админ-панели

## Быстрый старт

### 1. Установка зависимостей

```bash
yarn install
cd admin-ui && yarn install && cd ..
```

### 2. Настройка

Убедитесь, что в файле `.env` указан порт для админки:
```
ADMIN_PORT=3000
```

### 3. Запуск

#### Вариант 1: Разработка (с hot-reload)

Терминал 1 - Backend API:
```bash
yarn admin
```

Терминал 2 - Frontend dev server:
```bash
yarn admin:dev
```

Откройте `http://localhost:5173` в браузере

#### Вариант 2: Продакшн

Сначала соберите frontend:
```bash
yarn admin:build
```

Затем запустите сервер:
```bash
yarn admin
```

Откройте `http://localhost:3000` в браузере

## Использование

### Главная страница
- Показывает общую статистику по всем пользователям
- Количество активных пользователей за последнюю неделю
- Тренировки за сегодня

### Пользователи
- Список всех зарегистрированных пользователей
- Клик по пользователю открывает детальную статистику
- Показывает количество дней тренировок и подходов

### Детали пользователя
- **Графики**: визуализация прогресса за последние 30 дней
- **Статистика по упражнениям**: средний и максимальный вес для каждого упражнения
- **История тренировок**: полная таблица всех подходов с датами
- **Оплата**: информация о количестве оплаченных и оставшихся тренировок

### Упражнения
- Список всех упражнений, сгруппированных по категориям
- Клик по упражнению открывает детальную статистику

### Детали упражнения
- **График прогресса**: изменение среднего и максимального веса за 90 дней
- **Статистика по пользователям**: кто выполняет упражнение и с какими весами
- Общее количество подходов

## API Endpoints

Все endpoints доступны по адресу `http://localhost:3000/api`

### Общая статистика
```
GET /api/stats
```

Возвращает:
- totalUsers - всего пользователей
- totalWorkouts - всего подходов
- totalExercises - всего упражнений
- activeUsers - активных за неделю
- todayWorkouts - тренировок сегодня

### Пользователи
```
GET /api/users
```

Возвращает список всех пользователей с их статистикой

### Тренировки пользователя
```
GET /api/users/:userId/workouts?limit=50&offset=0
```

Параметры:
- limit - количество записей (по умолчанию 50)
- offset - смещение для пагинации (по умолчанию 0)

### Статистика пользователя
```
GET /api/users/:userId/stats
```

Возвращает детальную статистику пользователя

### Упражнения
```
GET /api/exercises
```

Возвращает список всех упражнений

### Статистика упражнения
```
GET /api/exercises/:exerciseId/stats
```

Возвращает детальную статистику по упражнению

## Технические детали

### Backend
- **Express** - веб-сервер
- **CORS** - разрешение cross-origin запросов
- **better-sqlite3** - работа с базой данных

### Frontend
- **React 18** - UI фреймворк
- **Vite** - быстрая сборка
- **TailwindCSS** - стилизация
- **Recharts** - графики
- **React Router** - навигация

### База данных
Использует ту же SQLite базу, что и Telegram-бот (`workout.db`)

## Решение проблем

### Порт уже занят
Измените `ADMIN_PORT` в файле `.env`

### Ошибка подключения к API
Убедитесь, что backend запущен (`yarn admin`)

### Пустая статистика
Проверьте, что база данных `workout.db` существует и содержит данные
